# VAROLUŞSAL KAYGI ÜRETEN MAKİNE

## Bu Repo Nedir?

Bu, insanlık tarihinin en büyük icadıdır. Belki de değildir. Belki de hiçbir şey değildir. Belki de sadece bir Python scriptidir ve sen şu anda zamanını boşa harcıyorsundur. Hoş geldin.

### Amaç

Dünyanın en gereksiz, en absürt, en varoluşsal kaygı üreten makinesini yaratmak. Çay içmekten daha önemli mi? Bilim insanları hala tartışıyor. Bu makine, senin hayatını sorgulatacak mesajlar üretir. Sonsuza kadar. Ya da Ctrl+C basana kadar.

### Nasıl Çalışır?

```bash
python kaygi.py
```

Sonra otur ve hayatının anlamını sorgula. Makine sana yardım edecek. Ya da etmeyecek.

### Özellikler

- Tamamen Türkçe varoluşsal krizler
- Rastgele ve absürt
- Gerçekten çalışır (inanmıyorsan dene)
- Hiçbir pratik faydası yok
- Çay demlenirken düşünülmesi gereken şeyler listesi
